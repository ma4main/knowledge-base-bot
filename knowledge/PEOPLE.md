# Кто есть кто в отделе

Справочник людей для бота: имена и зоны ответственности. Только зоны — без
характеров, стиля речи и оценок. Бот не расшифровывает `@ник` в имя, если пары
здесь нет, и не назначает людям задачи. Состав меняется — правьте здесь, файл
обычный Markdown в git.
