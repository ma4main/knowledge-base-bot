# Владение ботом: что он делает сам и что делать человеку

Для двух людей: **руководителя** (пользуется ботом, знает команду) и **техника**
(один раз развернул сервер, потом нужен редко). Программировать не требуется.

## 1. Что бот делает сам

Бот рассчитан на работу без присмотра. Сам, без человека, он:

- отвечает на вопросы в личке и в рабочих чатах;
- записывает в базу то, что ему диктуют, после того как автор подтвердил
  формулировку; под записью остаётся имя и дата;
- каждый вечер в 21:00 разбирает рабочие чаты и записывает новое с пометкой
  «не подтверждено»;
- раз в сутки отправляет в git поток чатов, файлы и снимок своего состояния;
- переключается на запасную модель, если основная недоступна;
- перезапускает сам себя, если связь с Telegram зависла дольше 15 минут;
- чистит собственную очередь нерешённых пунктов через 14 дней.

## 2. Когда бот пишет руководителю

| Сообщение | Что значит | Что делать |
|---|---|---|
| 🔑 Просит доступ | новый человек нажал `/start` | «Дать доступ» или «Отказать» |
| 📌 Меня добавили в чат | бота добавили в новый чат; до ответа он его не записывает и молчит | «Рабочий, записывать» или «Клиентский, нет» |
| 🤖 Неделя в базе знаний | отчёт по понедельникам | ничего; увидели ошибку, кнопка «↩️» откатит запись |
| 🔴 Не могу достучаться до модели | кончился баланс OpenRouter или сняли модель | раздел 5.1 |
| 🟠 Правки не уезжают в git | сбой хранилища | позвать техника, раздел 5.2 |
| 🟠 Заканчивается место | диск сервера | позвать техника, раздел 5.3 |
| 👥 Назначен / снят руководитель | кто-то сменил состав | убедиться, что это ожидаемо |

Если не отвечать ни на что из этого, бот продолжит работать. Хуже станет только
без денег на модель: он перестанет отвечать. Всё остальное безопасно по умолчанию:
новый чат без ответа не записывается, новый человек без ответа доступа не получает.

## 3. Руководителю: всё управление в боте

Кнопка «☰ Меню» или `/menu`.

- **Люди и доступ.** Выдать и забрать доступ, назначить и снять руководителя.
  Руководителя выбирают из списка людей с доступом. Последнего руководителя снять
  нельзя. Передать управление: назначить преемника, затем снять роль с себя.
- **Управление → Чаты.** Какие чаты записываются. Клиентские должны быть выключены.
- **Управление → Бот.** Модель, расход, выключатель автозаписи из чатов.
- **Управление → Качество.** Оценки ответов, идеи сотрудников, частые вопросы.
- **База.** Что изменилось за период, гипотезы без итога, очередь ночного разбора.

Необязательный ритуал на 10 минут в неделю: прочитать отчёт понедельника. Раз в
месяц заглянуть в «Качество → Оценки ответов» и «База → Гипотезы без итога».

## 4. Сотруднику: как пользоваться

- **Спросить.** Своими словами в личке: «какой тариф на Карты», «клиент говорит,
  что заявок нет». В рабочем чате: тегнуть бота или ответить на его сообщение.
- **Записать.** «Запомни: …» в личке, кнопка «✏️ Внести в базу» под ответом,
  пересланное сообщение, тег бота в рабочем чате с фактом. Бот покажет, как
  именно запишет, и спросит «верно?».
- **Файлы и ссылки.** Прислать файл с подписью, и он попадёт в библиотеку.
  «Запомни ссылку …» добавляет ссылку. «Пришли презентацию по Картам» и
  «дай ссылку на зум» достают их обратно.
- **Оценить ответ.** Кнопки под ответом: руководитель увидит оценки в меню.

## 5. Если что-то сломалось

### 5.1. «Не могу достучаться до модели»

1. https://openrouter.ai → Credits: пополнить баланс. Это причина в девяти случаях из десяти.
2. Если баланс есть, модель могли снять: Меню → Управление → Бот → Модель → выбрать другую.
   Запасные модели заданы в `bot/.env` и включаются сами.
3. Если не помогло, технику: `docker compose logs --since 1h | grep -i openrouter`.

### 5.2. «Правки не уезжают в git»

Бот работает, правки целы на сервере, нет только их копии в GitHub.

```bash
cd /opt/kb-bot && git status && git log origin/main..HEAD --oneline
ssh -T git@github.com            # жив ли deploy-ключ и есть ли право записи
git pull --rebase --autostash && git push origin main
```

Частые причины: у ключа отозвали право записи, репозиторий переименовали
(поправить `git remote set-url origin …`), незавершённый rebase (`git rebase --abort`).

### 5.3. «Заканчивается место»

```bash
docker builder prune -af         # старые сборки, обычно это гигабайты
df -h /
```

### 5.4. Бот молчит

```bash
cd /opt/kb-bot/bot && docker ps && docker compose logs --tail 50
docker compose restart
```

`unhealthy` дольше 15 минут бот лечит сам перезапуском. Если контейнер падает сразу
после старта, в логе будет причина: нет токена, `KB_ROOT` не на базу.

### 5.5. Все руководители недоступны

Аварийный вход: вписать новый числовой ID в `LEADER_IDS` в `bot/.env`, затем
`docker compose up -d`. ID импортируется в состояние один раз. Свой ID человек
узнаёт командой `/whoami`, она отвечает и тем, у кого доступа ещё нет.

## 6. Технику: редкие операции

| Операция | Как |
|---|---|
| Обновить код | `cd /opt/kb-bot && git pull --rebase --autostash && cd bot && docker compose up -d --build` |
| Поправить базу руками | править `knowledge/**.md`, коммит, push; бот подхватит за минуту |
| Сменить ключи | `/opt/kb-bot/bot/set-secrets.sh`, затем `docker compose up -d` |
| Самопроверка без ключей | `docker run --rm -e KB_ROOT=/app/kb -v /opt/kb-bot:/app/kb:ro -v /opt/kb-bot/bot:/app/bot bot-kb-bot python selfcheck.py` |
| Архив переписки и логов | `tar -czf /root/kb-bot-data-$(date +%F).tar.gz -C /var/lib/docker/volumes/bot_kb-bot-data/_data .` |

Где что лежит:

| Что | Где |
|---|---|
| база знаний, ссылки, люди | `knowledge/` в репозитории |
| поток рабочих чатов | `chats-live/` в репозитории |
| библиотека файлов | `files/` в репозитории |
| снимок состояния бота | `bot-state/state.json` в репозитории |
| секреты | `bot/.env` на сервере, только там |
| живое состояние, логи, переписка, оценки | docker-том `bot_kb-bot-data` |

## 7. Сколько это стоит

- OpenRouter: единицы долларов в месяц на команду из десятка человек при десятках
  вопросов в неделю и ночном разборе чатов. Расход виден в меню:
  Управление → Бот → Расход. Подробнее: [`MODELS.md`](MODELS.md).
- Сервер: любой минимальный VPS.
- Внешние зависимости: Telegram Bot API, OpenRouter, GitHub. Больше ничего.
