# Поток рабочих чатов

Сюда бот пишет сообщения из чатов, которые руководитель разрешил записывать:
`<chat_id>/<YYYY-MM>.jsonl`. Файлы дописываются непрерывно и уезжают в git раз в сутки.
Руками не редактировать. Личные данные (телефоны, почты, чужие домены) вычищаются
до того, как текст увидит модель.
