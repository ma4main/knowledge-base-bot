# Библиотека файлов

Файлы, которые бот отдаёт менеджерам по запросу («пришли презентацию по Картам»):
презентации, инструкции, прайсы. Устроена как база знаний — обычные файлы в git.

Каждому файлу соответствует карточка `files/<имя>.md` с шапкой: `id` (вида `file-…`),
`title`, `tags`, `product`, `given` (дата версии) и `file` (имя бинарника в этой же
папке); тело карточки — описание своими словами, по нему бот ищет. Пример —
`primer-prezentacii.md`. Бинарники в папку кладёт сам бот при загрузке файла через
Telegram: создаёт карточку, транслитерирует имя и коммитит. Карточка без поля `file`
(или без бинарника рядом) в витрине показывается как «описан, но файла ещё нет».
Секреты и клиентские частности сюда не класть — то же правило, что для базы знаний.
