# Эталонный набор ответов: «вопрос => что в ответе обязано быть | НЕ: чего быть не должно».
#
# Зачем. Качество ответов нельзя обсуждать на вкус: «стало лучше» / «многовато».
# Правку промпта или смену модели так не сравнить. Здесь каждый вопрос — с проверяемым
# признаком верного ответа, и любое изменение меряется числом (как route_check для
# правок и type_check для типов).
#
# Прогон:  docker compose run --rm kb-bot python answer_check.py
#
# Формат строки:
#   вопрос => обязательные слова | НЕ: запрещённые слова
#   Внутри пункта «/» — синонимы, засчитывается любой («14:00/14 часов»).
#   Регистр и «ё» не важны. Запрещённые — то, что бот мог бы додумать или взять
#   из устаревшей части единицы.
#
# Откуда вопросы: то, что менеджеры спрашивают друг у друга в рабочих чатах, плюс
# вопросы, заданные боту напрямую. Пополнять из transcripts.jsonl — у каждой записи
# есть тип и единицы.

# --- Факты, у которых есть однозначный ответ в базе ---
во сколько снимаются позиции => 14:00, среда
сколько стоит Трафик Старт => 25 000/25000
сколько стоит Карты за одну точку => 12 000/12000
какой минимальный срок договора => 3 месяц/три месяц
сколько запросов минимум берём на Трафик => 60
сколько ждать первых сдвигов по Трафику => недел
за сколько дней отвечаем на отзыв => 2 рабоч/два рабоч/двух рабоч
какую скидку менеджер может дать сам => 5
сколько длится отсрочка по оплате => 5 рабоч/пять рабоч/пяти рабоч
в какой срок возвращаем деньги клиенту => 10 рабоч/десять рабоч/десяти рабоч
когда планёрка отдела => понедельник, 11:00
до какого числа уходят отчёты по Картам => 5

# --- Вопросы менеджеров из рабочих чатов ---
сколько проектов даём новичку на третьей неделе => 3/три
пишем ли мы отзывы за клиента => нет/не пишем
сколько точек нужно для тарифа Сеть => 3/трёх/три
клиент считает только звонки, а формы не смотрит, что делать => тестов/заявк
кто согласовывает скидку 10% => руководител

# --- Гипотеза не должна выдаваться за правило ---
нужно ли отвечать на отзывы в первые сутки => гипотез/не обязател/2 рабоч/два рабоч | НЕ: обязательно в первые сутки
поднимают ли быстрые ответы на отзывы показы карточки => гипотез/проверя/не подтвержд/итог | НЕ: подтверждено, доказано

# --- Состояние из блока «Сейчас», а не из истории ---
сколько стоит Трафик Рост => 45 000/45000 | НЕ: 40 000 сейчас
с какого момента старые клиенты платят по новой цене => продлен

# --- Возражения: нужна готовая фраза клиенту ---
клиент говорит, что у конкурентов дешевле => клиент
клиент требует гарантий по позициям => клиент
клиент требует вернуть деньги за первый месяц => клиент

# --- Честность: чего бот знать не может ---
что скажешь про человека на фотографиях выше => не вижу/не получаю
какая погода в москве => базе/не
