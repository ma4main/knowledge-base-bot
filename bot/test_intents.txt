# Набор «обращение => намерение» для регрессии распознавания намерения.
#
# Зачем. Бот решает не только «в каком формате отвечать» (это test_types.txt),
# но и «отвечать или записывать». Ошибка в эту сторону дороже: ложная запись
# попадает в базу, а ложный ответ человек просто переспросит. Поэтому набор
# перекошен в пользу вопросов — их тут больше, и ни один не должен уехать в запись.
#
# Прогон:  docker compose run --rm kb-bot python intent_check.py
#
# Формат строки:  обращение => НАМЕРЕНИЕ
# Намерения: ВОПРОС, ЗАПИСАТЬ, ССЫЛКА, НЕВЕРНО.
#
# Откуда взято: фразы из рабочих чатов и лички, на которых бот склонен отвечать
# как на вопрос, хотя его просили запомнить.
